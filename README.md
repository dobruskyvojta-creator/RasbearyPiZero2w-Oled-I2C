# RasbearyPiZero2w-Oled-I2C

A small project for testing and using OLED displays and other hardware components with the **Raspberry Pi Zero 2 WH**.

The goal of this project is to create a small system stats display using an I2C OLED display:
- CPU temperature
- Date and time
- Battery status (Waveshare UPS HAT)
- IP address
- More sensors in the future

---

## Setup | `SETUP.sh`

To install all required dependencies and prepare the Raspberry Pi, run:

```bash
bash SETUP.sh
